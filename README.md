# zachrm

## Сканирование библиотеки на Android

На экране библиотеки можно просканировать папки `Download`, `Downloads`,
`Documents` и `Books` или выбрать отдельную папку. Поддерживаются файлы PDF,
EPUB, FB2, CBZ и CBR. Архивы CBZ/CBR отображаются группами по папкам, где они
найдены, а главы внутри папки сортируются по номеру в имени. Для сканирования стандартных папок Android 11 и новее
запрашивается специальное разрешение на управление файлами; на более ранних
версиях запрашивается разрешение на хранилище. Если доступ запрещён, его можно
выдать в настройках приложения или выбрать папку повторно после разрешения.
